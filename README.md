## My Album Catalog

My Album Catalog is a full-stack web aplication where users can catalog their favorite albums and songs. This app is designed to be simple to use, customizable, and give users an organized way to catalog their music. 

# Features

* Access to rich selection of albums/artists through the Last.FM api
* rating albums and adding detailed reviews
* rating/reviewing individual tracks
* supports multipls catalogs per user
* filters for sorting albums based off certaom fields (rating, date, A-Z, etc.,)
